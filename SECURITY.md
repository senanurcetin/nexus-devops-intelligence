# Security policy

This is an early-stage, read-only developer tooling MVP. It is not a security scanner or a production-certified monitoring platform.

- **Do not** post tokens, private build logs, customer data, credentials, or exploit details in public issues.
- Report potential vulnerabilities privately by emailing senanur.cetin.work@gmail.com with the subject `NEXUS security report`.
- The public demo uses anonymous GET requests to GitHub only; it does not require or accept user credentials.
- GitHub App integration, private repositories, webhooks and write access are not implemented.
- Security fixes are developed for the current main branch; no support period is guaranteed for pre-release snapshots.
